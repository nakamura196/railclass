データセット

RailClass は、日本を除く世界の鉄道車両の形式 14,346 件を、Wikidata と結んだ Linked Data として公開するデータセットです。このページに、件数・ファイル・URI・ライセンス・典拠をまとめました。同じ内容を機械が読める形（VoID と DCAT）でも置いています。

最終更新: 2026-10-15 · VoID (Turtle) · JSON-LD

URI と取り出し方

形式の URI は https://w3id.org/railclass/<ID> です。<ID> は Wikidata の Q 番号（例: Q696668）か、Wikidata に項目の無い形式に付けた独自の ID（tb- で始まる）です。

URI は w3id.org の恒久 URI で、サイトの置き場所が変わっても変わりません。ブラウザで開くと人が読むページが出ます。Accept: text/turtle か application/ld+json を付けて求めると RDF が返ります（w3id.org がファイルへ転送します）。

ファイルは https://railclass.ldas.jp/ にも置いてあります。ページの .html を .ttl か .jsonld に替えたものです（例: https://railclass.ldas.jp/rdf/class/Q696668.ttl）。

例: https://w3id.org/railclass/Q696668 · https://w3id.org/railclass/tb-skytrain-mk2

SPARQL について

SPARQL エンドポイントはありません。サイトは静的なファイルだけで動いています。

問い合わせたいときは、all.ttl を手元の RDF データベース（Oxigraph、Apache Jena など）や rdflib に読み込んでください。全体で 236,055 トリプル（Turtle で 8.5 MB）なので、ノート PC で数秒で読めます。

1 件ずつ見るなら、LD Browser（ブラウザだけで動く Linked Data の閲覧ツール）で URI を開けます。

CC0 1.0。値の多くは Wikidata（CC0）から取りました。
形式の写真
Wikimedia Commons のファイルごとの条件に従います。RDF には写真の IRI だけを入れています。
路線の線（GeoJSON）
© OpenStreetMap contributors、ODbL。RDF に入れているのは路線の Wikidata の ID だけです。
ERATV の型式番号と型式名
欧州鉄道庁（ERA）の ERATV によります。出典を示せば複製してよい、という ERA の著作権表示に従っています。

典拠と作り方

  • 形式の一覧と値: Wikidata。鉄道車両の形式に当たる項目を SPARQL で集め、日本の形式を除きました。
  • 走る路線: Wikidata の P3438（通常使う車両）と、出典を付けて手で埋めた表。路線の線は OpenStreetMap から切り出しました。
  • ERATV との対応: ERATV の型式の一覧と Wikidata の形式を、名前で自動照合しました。人の目では確かめていません。
