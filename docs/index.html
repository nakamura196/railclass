できること

  • 形式を探す国・運行者・製造者などで絞り込み、世界の形式を一覧します。
  • 地図から探す 準備中形式が走る地域を地図に出し、そこから探します。
  • 3D で見る車体を回して見られます。部位の説明も付ける予定です。
  • ダウンロード 準備中GLB・STL・3MF などの形式で、3D プリントや CAD に使えます。
  • データとして使う形式の情報を RDF、3D モデルを IIIF で公開します。

    お知らせ

      このサイトについて

      鉄道車両の「形式」（同じ設計で作られた車両のまとまり）を、Wikidata などの典拠から集めています。日本の形式は含みません。

      3D モデルは、作者がおもちゃの車台（プラレール）に載る大きさで作った車体です。実物の縮尺模型ではありません。モデルごとに、どの形式のどの塗装かを結んでいます。

      作者: 中村 覚（東京大学）

      データ

      • 3D モデルの一覧（JSON）名前・寸法・Wikidata の形式 ID・追加日
      • 形式の RDF（Turtle・JSON-LD） 準備中形式ごとと、全件をまとめたファイル
      • IIIF Manifest（Presentation 4.0） 準備中3D モデルごとと、全体の Collection
      • ダウンロード 準備中GLB・STL・OBJ・3MF・STEP
