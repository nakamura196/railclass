Dataset

RailClass publishes 14,346 railway vehicle classes from outside Japan as Linked Data, linked to Wikidata. This page puts the counts, files, URIs, licences and sources in one place. The same description is also available for machines (VoID and DCAT).

URIs and how to get the data

A class is https://w3id.org/railclass/<ID>. <ID> is the Wikidata Q id (e.g. Q696668), or an ID of our own starting with tb- for the few classes Wikidata has no item for.

The URIs are persistent w3id.org URIs: they stay the same if the site moves. Opening one in a browser shows a page for people; asking with Accept: text/turtle or application/ld+json gives the RDF (w3id.org sends the request on to the file).

The files are also at https://railclass.ldas.jp/: the URI's page with .ttl or .jsonld in place of .html (for example https://railclass.ldas.jp/rdf/class/Q696668.ttl).

Examples: https://w3id.org/railclass/Q696668 · https://w3id.org/railclass/tb-skytrain-mk2

About SPARQL

There is no SPARQL endpoint. The site is static files only.

To query the data, load all.ttl into a local triple store (Oxigraph, Apache Jena, ...) or rdflib. It is 236,055 triples (8.5 MB of Turtle) and loads in seconds on a laptop.

To look at one resource, open its URI in LD Browser, a Linked Data browser that runs in the browser alone.

Sources and method

  • Classes and their values: Wikidata. The items that are railway vehicle classes were collected with SPARQL; Japanese classes are left out.
  • Lines: Wikidata P3438 (vehicle normally used), and a hand-filled table with sources. The tracks were cut out of OpenStreetMap.
  • ERATV mapping: the ERATV type list matched to Wikidata classes by name, automatically. Not checked by hand.
